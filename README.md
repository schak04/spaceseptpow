# SpaceSept Pow!

This project is a 2D top-down space shooter game that I'm about to start writing in C++ using raylib.
This will, in fact, be my first raylib project.

> [!NOTE]  
> The name is made from three ideas:
>
> - Space refers to the spaceship and the game's setting.
> - "Sept" comes from my name (Saptaparno; nickname/shortened name: Sapto).
> - Pow is an onomatopoeic expression associated with shooting, since this is a space _shooter_.
>
> What can I say, well, I know the name is a bit wanky but I like it because this is the most meaningful name I could come up with.
