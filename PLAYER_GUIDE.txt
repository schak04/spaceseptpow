SpaceSept Pow!

Getting started
---------------

Keep the game and assets together in the extracted package.

Linux: Extract the .tar.gz package and launch spaceseptpow from the extracted
folder.

Steam Deck: Switch to Desktop Mode, download and extract the Linux .tar.gz
package, then add spaceseptpow as a non-Steam game in Steam. Return to Game Mode
to launch it. The game supports Steam Deck controls for movement, shooting, 
starting, restarting, viewing credits, pausing, and quitting.

Windows: Extract the ZIP file and launch spaceseptpow.exe.

macOS: Open the DMG and drag spaceseptpow.app to Applications. The app is not
signed or notarised yet, so macOS may block its first launch. Control-click the
app and choose Open to allow it.

Controls
--------

| Keyboard           | Gamepad            | Action                 |
| ------------------ | ------------------ | ---------------------- |
| WASD / Arrow Keys  | Left stick / D-pad | Move                   |
| Space              | A                  | Shoot                  |
| Enter              | Start / Menu       | Start or restart       |
| Escape             | Start / Menu       | Pause or resume        |
| Hold Escape        | Hold Start / Menu  | Quit after 1.5 seconds |
| C                  | Y                  | Open credits           |
| K                  | X                  | Open keybinds          |
| F                  | View / Select      | Toggle fullscreen      |
| C / Enter          | Y / Start / Menu   | Return from credits    |
| Escape / K / Enter | B / X / Start/Menu | Return from keybinds   |
